# NFT Marketplace

A complete NFT marketplace built with Solidity, Hardhat, and React.

## 🚀 Features

- Mint NFTs with custom metadata
- List NFTs for sale
- Buy NFTs from the marketplace
- Test coverage with Hardhat
- React frontend for interaction

## 📋 Prerequisites

- Node.js v16+
- MetaMask
- Git

## 🛠️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/nft-marketplace.git
cd nft-marketplace
npm install
